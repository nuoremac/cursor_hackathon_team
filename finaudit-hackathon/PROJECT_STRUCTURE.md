# FinAudit Project Folder Structure

This folder is organized by responsibility so each teammate can work quickly without blocking the others.

## Folders

- `01-frontend-ui`: dashboard, transactions table, filters, charts, visual polish.
- `02-data-audit-logic`: CSV parsing, transaction types, anomaly detection rules, dashboard metrics.
- `03-ai-api`: AI or mock-AI anomaly explanation endpoint and frontend integration contract.
- `04-product-pitch-demo`: pitch, demo script, screenshots, final story, value proposition.
- `05-integration-qa-deployment`: final runnable app, integration, testing, deployment, local backup.
- `shared/demo-data`: CSV demo data used by everyone.
- `shared/docs`: common documentation, pitch notes, screenshots.
- `shared/types`: shared TypeScript interfaces or schema notes.

## Rule

Each person can prototype inside their folder, but the integration lead owns the final app version and decides when code is merged into the runnable demo.
